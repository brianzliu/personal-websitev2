# Brian's projects

## FlashMath (2026, independent project)
AI-assisted math study desktop app. Built with Tauri, Rust, React, and TypeScript. A cross-platform study app with local persistence, screenshot and PDF ingestion, LaTeX rendering, provider-agnostic AI OCR, and an exam-aware version of the SM-2 review algorithm. Code: https://github.com/brianzliu/FlashMath

## Blueprint (Jan 2026, NexHacks, 1st place DevTools)
Codebase summarization and vulnerability detection. Built with TypeScript, React Flow, D3.js, AST parsing, Gemini, and bear-1. A VS Code extension that extracts repository structure, maps file dependencies, summarizes code at multiple levels, and flags security risks. Tested on repositories as large as MongoDB. Devpost: https://devpost.com/software/unnamed-pzmyes

## CARP (Oct 2025, Sushi Hackathon at Stanford, 3rd place)
Health monitoring and catch optimization system. Built with Arduino, Python, Bluetooth, Random Forest, and RAG. An FSR-402 pressure-sensing brace with Bluetooth telemetry, live carpal-tunnel risk scores, alerts, historical trends, and a fishing dashboard built around more than 50,000 geospatial data points. Slides: https://docs.google.com/presentation/d/1G8c4U542EkD4S2SwFdJhdvmzZ8a2mNtRQ0Zzb5SSXFg/edit?slide=id.g388d26c538d_3_786

## Bouncer (Jun 2025, Berkeley AI Hackathon)
Malicious actor prevention system. Built with React Native, Supabase, Claude, Gemini, and Google Search. An access-control dashboard that searches public records from signup data, produces an explained risk score, and alerts administrators when a user crosses a configurable threshold. Devpost: https://devpost.com/software/bouncer-7cvsgz

## CiteTrace (May 2025, ACM x Intel Hackathon, 1st place)
Research knowledge graph. Built with React Native, TypeScript, D3.js, RAG, and Supabase. An interactive graph that connects uploaded academic work, explains relationships between papers, and lets researchers query their literature with grounded citations. Devpost: https://devpost.com/software/inciteful

## PillSnap (Apr 2025, UCSD DiamondHacks, Best Use of Auth0)
AI-powered pill identifier. Built with Gemini, Vertex AI, the FDA API, Cloud Run, and Vercel. A pill-identification app that combines image descriptions with FDA data, saves medication details, and surfaces drug and food interaction warnings. Devpost: https://devpost.com/software/pill-snap

## Low-Cost Blind Navigation Apparatus (Sep 2022 to Feb 2023, independent research)
Wearable computer-vision navigation aid. Built with Python, OpenCV, YOLOv4-tiny, and a Raspberry Pi. A Raspberry Pi head-worn navigation system with real-time audio feedback. Its object detector reached 87.34% mAP while reducing hardware cost by about 90% against commercial alternatives.
